常见问题

我的文件会被上传吗？

不会。PDF 解析、渲染、水印、合并、转换、加密和解密都在当前浏览器标签页内完成。我们没有接收文件的服务器接口。页面关闭或刷新后，当前会话的数据会从内存中释放。

支持哪些文件格式？

输入支持 PDF、PNG、JPG/JPEG。输出支持 PDF、PNG、JPEG 和 ZIP（多页图片）。加密功能使用 AES-256；解密支持常见的 PDF 标准加密，极少数特殊格式会回退到逐页渲染。

如何拆分不连续的页面？

在「页面拆分」中切换到「离散多选」，然后点击缩略图，或直接输入页码，例如 3, 15, 88。连续页面使用「范围区间」，起止页都会包含在结果中。

为什么导出的 PDF 里水印和我看到的不一样？

水印会实时显示在画布上，并自动包含在导出文件中。请确认「应用页范围」是否正确；如果使用单点模式，水印只出现一次；平铺模式的间距和旋转角度也会影响最终效果。导出后建议打开检查。

编辑时如何撤销和重做？

使用 Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。输入框聚焦时快捷键不会触发，避免误操作。页面顺序可以通过拖拽左侧缩略图调整。

遮罩（Redaction）能恢复吗？

不能。遮罩会以黑色块写入导出的 PDF，覆盖区域的内容无法通过本工具恢复。请保留原始文件，并确认遮罩范围后再导出。

合并后的页面顺序为什么和添加顺序不同？

合并按文件列表从上到下的顺序拼接。拖动列表可以调整顺序；合并前请确认每个文件的页数和位置。合并结果也可以直接送入编辑精修继续调整。

PDF 转图片应该选多少 DPI？

屏幕查看和聊天分享通常 150 DPI 足够；打印、存档或需要放大查看细节时建议 300 DPI 或更高。DPI 越高，图片尺寸和文件体积越大。

PDF 加密的权限限制能阻止所有复制吗？

不能。PDF 权限是阅读器层面的建议性约束，不是 DRM。它可以减少误操作和普通复制，但不能阻止截图、拍照或使用专门工具处理。加密也不会隐藏文件元数据。

没有密码也能解密吗？

不能。对于需要打开密码的 PDF，必须输入正确密码。本工具不会猜测、暴力破解或绕过未知密码。对于只限制复制/打印、但能正常打开的 PDF，可以移除权限限制。请只处理你拥有或已获授权处理的文件。

解密后文字还能搜索和复制吗？

现在的解密使用无损移除加密，通常会保留文本层、矢量图形和书签，因此可以继续搜索和复制。极少数不支持的加密格式会回退到逐页渲染，那种情况下文字会变成图片。

支持哪些浏览器？

建议使用较新的 Chrome、Edge、Firefox 或 Safari。浏览器需要支持 ES Modules、Web Worker 和 WebAssembly。过旧的浏览器或禁用 JavaScript 时无法运行。

操作指南

如何在不泄露文件的情况下拆分 PDF

  1. 打开「页面拆分」，拖入 PDF 或点击选择文件。
  2. 选择「范围区间」并填写起止页，或切换到「离散多选」点选页面。
  3. 查看右侧的起止页预览，确认没有选错章节。
  4. 点击导出，浏览器会直接生成并下载新的 PDF。

整个过程不上传文件。如果源文件有打开密码，先用「PDF 解密」移除密码，再回到拆分页。

水印和遮罩有什么区别？

水印用于标识文件，例如「机密」「草稿」「仅供内部」，可以平铺或单点，并调整字号、透明度、旋转和颜色。遮罩用于隐藏敏感内容，会在导出的 PDF 中写入不可恢复的黑色块。

如果目的是提醒阅读者，使用水印；如果目的是让某些文字或图片彻底不可见，使用遮罩。两者都可以在「编辑精修」中完成。

PDF 的权限密码和打开密码

打开密码（User Lock）要求每次打开文件时输入密码；权限密码（Owner Lock）不阻止打开，但限制打印、复制、编辑等操作。加密页面可以同时设置两者，并逐项选择允许的权限。

解密页面可以移除你能打开文件的权限限制，或在你已知密码的情况下移除打开密码。请只处理你拥有或已获授权处理的文件。
