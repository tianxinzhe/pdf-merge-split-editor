关于 Lemon PDF Studio

把常用的 PDF 操作放在一个页面里，同时让文件留在你自己的设备上。

本地优先。 所有 PDF 和图片处理都在浏览器内完成：不上传、不注册、不建立文件库。关闭页面后，会话数据随内存释放。

为什么做这个工具

很多在线 PDF 工具要求先上传文件，再等待服务器处理。对于合同、发票、身份证扫描件和内部资料，这往往不是理想选择。Lemon PDF Studio 使用浏览器自带的渲染与 PDF 处理能力，把拆分、合并、编辑、加水印、遮挡、转换、加密和权限管理放到本地完成。

包含哪些模块

页面拆分

按范围或离散页码提取页面，导出前可预览起止页。

编辑精修

排序、删除、旋转、撤销重做，文字/图片水印与遮罩。

多文件合并

PDF 与图片混合添加，拖拽排序后合并，或送入编辑器。

PDF 转图片

72–600 DPI，PNG/JPEG，单张或拼接长图。

图片转 PDF

多张 JPG/PNG 按顺序合成为 PDF，适合扫描件归档。

PDF 权限管理 / 加密

移除你有权访问文件的权限限制，或添加 AES-256 密码与权限。

技术实现

界面使用 React、TypeScript、Vite 和 Tailwind CSS。PDF 渲染与解析使用 pdf.js 与 pdf-lib，加密与权限管理使用 LibPDF。PDF.js 的字体、CMap 和 WASM 资源随站点一起部署，因此中文字体和扫描件解码可以离线工作。

开源

项目代码托管在 GitHub。欢迎提交问题、建议或改进。站点通过广告支持托管成本，广告不会改变文件的本地处理方式。
