联系我们

这是一个开源项目。反馈、功能建议和问题报告通过 GitHub Issues 处理。

GitHub Issues

提交问题时，请尽量附上：

  • 使用的模块（拆分、编辑、合并、转换、加密或权限管理）；
  • 浏览器与操作系统版本；
  • 问题现象和复现步骤；
  • 如涉及 PDF 结构，可提供脱敏后的最小测试文件。

反馈类型

功能建议

希望增加或改进的 PDF 操作、格式或语言。

问题报告

页面报错、导出异常、字体或扫描件显示问题。

隐私请求

与本地存储、广告 Cookie 或隐私政策有关的问题。

安全报告

请避免公开敏感细节，先在 Issue 中说明需要私下沟通。

请不要发送

请勿在公开 Issue 中上传包含身份证号、银行信息、医疗记录、未脱敏合同或其他敏感内容的文件。你可以用一份结构相同、内容虚构的 PDF 复现问题。

响应时间

维护者会尽量在空闲时间处理。安全检查会优先，但无法保证固定响应时限。

Contact (English)

This is an open-source project. Please use GitHub Issues for bug reports, feature requests, privacy questions and security reports.

Include the module, browser/OS, steps to reproduce and, if needed, a redacted minimal PDF. Do not post ID cards, bank statements, medical records or unredacted contracts publicly.
